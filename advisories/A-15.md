| | |
|---|---|
| **Product** | CHMLib (jedwing) — CHMLib |

| **CVE ID** | requested from MITRE CNA-LR on 2026-11-24 — pending |

## Description

CHMLib 0.40 reads out of bounds in _chm_parse_UTF8() in src/chm_lib.c. The function copies "count" bytes from the input without verifying that the source buffer holds that many bytes, so a crafted .chm file causes a heap out-of-bounds read. The supplier's last commit is 2009-07-02; 0.40 is the final release and the supplier could not be contacted.

## Proof of concept

```
d_utf8oob.chm
```

## Verification

ASan heap-buffer-overflow at src/chm_lib.c:1129

Every proof of concept was executed **five times in independent runs** with a freshly
created working directory. All runs produced an identical signature and crash location;
no flaky or environment-dependent results were observed. See
[`../VERIFICATION.md`](../VERIFICATION.md).

## Workaround

Do not open untrusted .chm files with applications linking CHMLib. Upstream's last commit is 2009-07-02 and there has been no release since.

## Solution

No fixed version is available. 0.40 is the final release and upstream is unmaintained.
